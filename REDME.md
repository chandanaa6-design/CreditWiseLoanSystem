

# 💳 Credit Wise Loan Prediction System

## 📌 Project Overview

This project predicts whether a loan application will be approved based on applicant details such as income, loan amount, and credit history.
It uses Machine Learning techniques to analyze patterns and make predictions.

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Seaborn
* Matplotlib
* Scikit-learn

---

## 📊 Features

* Data preprocessing and cleaning
* Handling missing values
* Exploratory Data Analysis (EDA)
* Correlation heatmap visualization
* Model training using Logistic Regression
* Loan approval prediction

---

## 🤖 Model Used

* Logistic Regression

## ⚠️ Dataset Information

The dataset is **not included** in this repository.

To run this project:

1. Add your dataset file named:
   loan_approval_data.csv
2. Place it in the same folder as the notebook

---

## ▶️ How to Run

1. Open the project in VS Code or Jupyter Notebook
2. Install required libraries:
   pip install pandas numpy seaborn matplotlib scikit-learn
3. Run all cells in the notebook

---

## 📌 Conclusion

This project demonstrates how Machine Learning can be used to automate loan approval decisions based on historical data.
